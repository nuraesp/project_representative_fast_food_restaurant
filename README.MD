\# Análisis de ventas de un restaurante de comida rápida representativo



\## Descripción del proyecto



Este proyecto consiste en el análisis de datos de ventas de un restaurante de comida ràpida representativo

utilizando los conocimientos aprendidos en el curso Excel Skills for Business: Essentials and Intermediate I

de Macquarie University y Coursera.



El objetivo es analizar el comportamiento de las ventas, estudiar el rendimiento de los diferentes productos 

y obtener estadísticas descriptivas a partir de los datos disponibles.



\## Dataset



El conjunto de datos contiene información relacionada con las ventas, incluyendo:



\* Nombre del producto

\* Cantidad vendida

\* Importe de la transacción

\* Fecha de la venta



\## Análisis realizado



El proyecto incluye diferentes análisis estadísticos y descriptivos:



\* Estadística descriptiva

\* Ventas por producto

\* Cantidad vendida por producto

\* Ventas según la franja horaria

\* Media

\* Varianza

\* Desviación típica

\* Visualización de datos

\* Tablas dinámicas
